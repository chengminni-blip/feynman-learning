# feynman-learning

一个基于《费曼学习法》（尹红心、李伟 著）整理的 **WorkBuddy Skill**，把费曼学习法的核心方法论做成了可随时调用的知识库，帮你在学习任何新知识、技能或概念时，用「输出倒逼输入」的方式真正学透、内化、形成自己的知识体系。

## 能帮你做什么

- 掌握费曼学习法**五部曲**：确立目标 → 理解 → 以教代学 → 回顾 → 简化
- 应用**五大原则**：目标 / 系统化 / 输出 / 回顾 / 简化
- 识别「假知识」「盲维」，用 SMART 原则校验目标
- 提升「内容留存率」，把知识真正内化为己用

## 内容结构

| 路径 | 说明 |
|---|---|
| `SKILL.md` | Skill 入口，含核心框架、判断规则、章节/主题索引 |

## 安装

把整个文件夹放到你的 Skill 目录下即可：

```bash
# 方式一：直接 clone（推荐）
git clone https://github.com/chengminni-blip/feynman-learning.git \
  ~/.workbuddy/skills/feynman-learning

# 方式二：下载 zip 解压后放入 ~/.workbuddy/skills/
```

> Skill 目录默认在 `~/.workbuddy/skills/`（用户级，所有项目可用）。放入后重启或刷新 WorkBuddy 即可被识别。

## 使用方法

在 WorkBuddy 对话中直接提问即可触发，例如：

- 「用费曼学习法帮我学 XX」
- 「什么是以教代学？」「SMART 原则是什么？」
- 「加载 ch12 章节」「有哪些章节？」

具体用法见 `SKILL.md` 的 *How to Use This Skill* 部分。
