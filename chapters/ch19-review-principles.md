# 第十九章 费曼技巧：回顾原则

## Core Idea
回顾原则是真正掌握知识的倒数第二步——把模糊、有疑义的内容摘录下来与资料对比，梳理出最精华的知识。

## Frameworks Introduced
- **回顾原则三步**：
  1. **怀疑和探索**：确保数据事实准确精确；对未知保持好奇心，怀疑一切定论（含权威）；探索知识本质和背后问题。
  2. **寻找反证**：重视否定式证据；对薄弱环节多方搜集、多角度理解；重视争议性观点。
  3. **加大内容留存率**：追求效能而非数量；把精力放到「有用的学习」；用原理性思维加大留存率。

## Key Concepts
- **理论化说明**：费曼本人并未将其方法理论化，这些原则由追随者和思维学家整理（费曼经验主要源于教学实践与学习心得总结）。

## Mental Models
- 用「我还能再简单直白些吗？小白能轻松理解吗？」做回顾后的最终检验。
- 用「在实践中检验方法、在理论上完善」对待优秀学习法。

## Anti-patterns
- **把回顾当终点**：厘清争议还不够，还要再简化到小白能懂。
- **忽略否定式证据**：只搜集正面信息会陷入倾向性。

## Key Takeaways
1. 回顾三步：怀疑探索 → 寻找反证 → 加大留存率。
2. 摘录证据不足、解释不清、逻辑不明、一知半解的内容逐一对比梳理。
3. 回顾后还要检验：能否再简单直白、让小白轻松理解。
