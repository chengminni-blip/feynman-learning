# 第二十章 好东西太多，也会消化不良

## Core Idea
学习最后一步是「简化」——把知识做成精小的「知识包」融入知识体系，避免贪多嚼不烂。

## Frameworks Introduced
- **八问测试**（美国管理协会，评估学习方式有效性）：每年读几本书？是否深知知识弱项？从哪学？发现错误是否调整？是否被惯性左右？如何证明独立思考？是否每天写心得？对疑义知识是否写深度分析？——牵涉主动学习、怀疑反省、原创思考三种能力。
- **简化知识两要点**：
  1. 打开「重要性开关」——为知识列优先级，全力吸收重要的（三次复述能训练语言组织、检查知识点、形成清晰逻辑）；
  2. 将知识从复杂回归简单——找到「核心逻辑」（乱麻的总线头），提升思考维度从高处找核心。
- **知识吸收五能力**（吸收能力，获取→简化→吸纳→转化→创新）：
  1. 获取知识（确立方向、判断关键知识）；
  2. 简化知识（提炼骨架要点）；
  3. 吸纳知识（转化为长时记忆、能阐释）；
  4. 转化知识（与已有知识结合成可用的能力）；
  5. 创新知识（在已有基础上创造新知识）。

## Key Concepts
- **简化 = 洗菜做饭**：清水洗净、剔除不需要的部分、留下有营养的、分别摆好。
- **重要性开关**：讲完知识后哪些重要/不重要突然清晰。

## Mental Models
- 用「乱麻找总线头」理解简化——所有复杂知识体系都有一个简单核心逻辑。
- 用「小学生能理解的语言重新总结」作为成功内化的标志。

## Anti-patterns
- **用复杂词语/专业术语掩盖不明白**：看似高大上，其实在糊弄自己。
- **好东西太多消化不良**：扩大读书量未必提高知识水平。

## Key Takeaways
1. 简化 = 分解出核心 + 条理化逻辑化，才谈得上吸收。
2. 用「重要性开关」排优先级，只吸收重要的。
3. 知识吸收五能力：获取、简化、吸纳、转化、创新。

- **Ch22**：简化的最终目的——内化为知识体系。
