# 第五章 规划：和目标建立「强联系」

## Core Idea
在目标与规划之间建立「强联系」，随时确保付出正确，避免努力多年才发现目标错误。

## Frameworks Introduced
- **强联系（两个必做环节）**：
  1. 论证学习这门知识的必要性（我真的需要吗？值得投入吗？）；
  2. 确认规划与目标的实质联系（计划与目标匹配度？可行吗？有更高效方法吗？）。
- **SMART 原则**（判断目标是否正确的标尺）：
  - **S**pecific 明确具体；**M**easurable 可量化；**A**chievable 能力可达；**R**ewarding 有成就感；**T**ime-bound 有时限。
- **舒适区两个标准**：① 符合兴趣的方向；② 能力范围内的合理目标。
- **三件预留时间**：锁定最重要目标、做正确规划、调整目标和规划。

## Worked Example
作者朋友小周，27 岁经历离婚争夺抚养权失败，立志「学理财致富」向人证明自己。
用 SMART 检验：
- S（清晰）✓ 想通过理财致富很明确；
- R（有意义）✓ 改善生活地位；
- M（量化）✗ 赚多少算成功？100 万还是 1000 万？
- A（可达）✗ 心性能力根本不足以在股市赚钱；
- T（时限）✗ 何时致富？巴菲特也给不出期限。
结论：错误目标。转而挖掘他真正的积累（工商管理+财务基础+两年中层管理经验），新目标是「学企业管理、提升管理与财务能力、找高薪工作」——这才是正确方向。

## Mental Models
- 用「计划和终点之间要有互动反馈」确保付出正确，收获正反馈。
- 「凡是能让你一夜暴富的知识全是假知识，目标也是假目标」。

## Anti-patterns
- **功利主义投资/学习**：动机错误的目标，会让之前的正确积累瞬间付诸东流。
- **高唱鸡血之歌却忽视可行性**：目标高大上、规划一塌糊涂。
- **把一个错误目标偏执到底**：聪明人善于反问反省，愚蠢者自我感动。

## Key Takeaways
1. 定目标前先论证必要性、确认规划与目标的实质联系。
2. 用 SMART 五条逐一检验目标，任何一条不符都要警惕。
3. 大目标拆成 3-5 个可落实的阶段小目标。
4. 学习的目的不是记住知识，而是建立思维框架并解决实际问题。
