# 第七章 归类和对比知识的来源

## Core Idea
理解知识的首要原则是把知识系统化——归类、解构、对比，筛选出可靠知识，分辨并剔除「假知识」。

## Frameworks Introduced
- **有逻辑地系统化（三件事）**：
  1. 明白自己学习是为了什么（目的要非功利、非倾向性、非偏执）；
  2. 拥有足够宽阔的视野（保持童真，多问「作者为什么写」）；
  3. 建立最可能客观科学的逻辑。
- **筛选知识的方法论**：
  - 锁定方向（清楚自己短板、重点学什么）；
  - 列需求清单（这本书哪些知识最需要、急需弥补什么）照方抓药；
  - 保留与需求匹配、可靠的知识。
- **分辨假知识**：
  - 屏蔽来源不确定的知识（公众号/论坛/道听途说）；
  - 审视不够专业权威的来源；
  - 对权威来源也要独立思考和谨慎采纳；
  - 小心对待差异化（互相冲突）的知识，务实结合理解；
  - 用对比方式挑选，删除重复和不可靠信息。

## Key Concepts
- **假知识**：具有「强意志」标签、刺激意志让人乐于接受、却改变不了行为、无法落地的知识（如「近视矫正手术能治愈近视」是错的，只能控制）。人一生学到的约 90% 是假知识。
- **三种错误学习取向**：纯功利性输入（应付考试）、倾向性输入（强化固有立场）、偏执性输入（内卷排他）——导致理解缺乏逻辑、系统 BUG。
- **系统化 = 画学习图纸**：把材料安放到该去的地方，利于对比筛选。

## Mental Models
- 用「先确立两到三个可靠知识来源，互相印证对比」替代「盲目狼吞虎咽」。
- 经验只是惯性行为模式，学习时忘掉过去的技能，避免「强意志」干扰判断。
- 用「摘菜洗菜」类比筛选知识——删掉坏叶子、洗掉泥土。

## Anti-patterns
- **罗振宇式选书（信一个作者就信他全部书）**：权威知识里也有水分。
- **坐井观天**：用有限知识构建逻辑闭环、循环论证，学得越多观点越偏狭。
- **成为假知识的无意识帮凶**：不辨真假地传播。

## Key Takeaways
1. 系统化是对知识理解是否透彻的试金石——不能系统化 = 没理解透。
2. 学习前先列需求清单，照方抓药地筛选。
3. 对来源分级：屏蔽不确定、审视不够权威、谨慎采纳权威。
4. 警惕「强意志」假知识（让人上瘾却无法落地）。
