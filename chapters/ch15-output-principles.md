# 第十五章 费曼技巧：输出原则

## Core Idea
学习要有「致用」的出口——学以致用，输出是双向过程，是知识转化的必经之路。

## Frameworks Introduced
- **五个输出原则**（递进且互相联系，缺一不可）：
  1. 为知识找到出口，去输出、使用它们；
  2. 输出是主动学习（倒逼输入）；
  3. 输出检验并强化认知；
  4. 输出获取反馈、修正判断；
  5. 通过输出把知识转化为自己的智慧与本领。

## Worked Example
富兰克林自学写作：① 剪下报纸文章，读一遍再抄一遍（抄在散乱纸条上）；② 打乱纸条顺序重新排列（理解文章结构）；③ 提高难度——不看原文，在白纸上默写读过的文章（复述），默写时不由自主加入自己的文字。一段时间后，文章刊登在报纸上。这是「复述→内化→创造」的经典闭环。

## Key Concepts
- **输出系统**：学了很多却觉得无用，不是知识无用，是没建立稳定的输出系统。

## Mental Models
- 用「学以致用」四字理解学习目的 + 学习策略（结合致用来学）。
- 用「为知识找一个或多个出口」衡量学习是否完整。

## Anti-patterns
- **只输入不输出**：知识没有出口，无法转化为本领和智慧。
- **把输出当单向传授**：输出本质是双向过程。

## Key Takeaways
1. 任何系统学习都要为知识找到「出口」去输出使用。
2. 输出的五个原则递进相连，缺一不可。
3. 输出是双向过程，最终把知识转化为智慧。
